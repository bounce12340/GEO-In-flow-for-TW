# UI language

Liekan supports Traditional Chinese for Taiwan (`zh-TW`), Simplified Chinese (`zh-CN`) and English (`en-US`). GEOInflow TW uses `zh-TW` when neither the browser nor `DEFAULT_LOCALE` states a preference; `DEFAULT_LOCALE=zh-CN` or an English value selects those defaults. Every product page provides the same immediate language selector at the upper right. Management pages use their header, website analytics use the shared website toolbar, and authentication, public shares and identity setup provide standalone entries. Required two-factor setup and recovery-code dialogs keep an entry inside the active dialog so it remains reachable while the background is blocked. The account menu and Preferences retain their synchronized selectors. The title or website and language control stay in the first header row; other actions wrap into the available space and use a separate row at widths up to 1200px. The selector keeps its accessible bilingual name and the existing toolbar sizes.

The browser saves an explicit choice in the same-origin `liekan.locale` cookie for one year and mirrors the legacy `umami.locale` storage entry. On initialization, a valid cookie takes precedence over legacy storage, a valid `locale` URL hint and the deployment default. Invalid values are ignored. Logout retains the choice. Separate browsers and devices retain their own choices. If browser policy blocks both storage mechanisms, the current page changes and the selector explains that the choice could not be saved. Server rendering reads the cookie for each request. Legacy preferences migrate before first-page content becomes visible.

Language changes preserve the current resource, dates, timezone, filters, sort, pagination, drafts, statistics snapshot and active tasks. Natural weeks remain Monday through Sunday. Resource names, page paths, event names, visitor content, raw logs, stored model responses, code examples, query literals and vendor names retain their original values. Metadata keeps geographic display names tied to stable country, region and city identities; unknown names retain the supplied name. City and province rankings follow the shared display rules; missing locations remain included in full-population coverage counts. Coverage and active-source attribution labels use the current interface language.

Native API reads and feature statistics keep their raw response cache identity across language changes through internal `localeInvariant` metadata. The interface translates their labels at render time. Other translated browser projections retain locale isolation, and raw responses retain the same resource authorization, version and expiry checks. Two-factor setup wraps the complete manual key within the dialog while the copy action retains its original bytes.

Charts retain legend choices and zoom during a language change on the same snapshot. Every feature chart declares an internal `interactionKey` from its canonical resource, conditions and raw response. The GEO chart derives the same identity from its raw report. A different snapshot, loading state or failed render clears the saved interaction state. Localized legend names are mapped by their positions within that verified snapshot; raw names and chart data retain their supplied values. Mobile navigation includes native form controls in its keyboard focus cycle.

English interface text resides in the catalogs under `src/lib/liekan/i18n`. Simplified Chinese source text remains the message identity. The Taiwan catalogs (`messages/zh-TW.json`, `help-messages/zh-TW.json`, `geography-zh-TW.json`) are generated by `pnpm liekan:zh-tw` from the Simplified catalogs with OpenCC (cn → twp), a Taiwan wording glossary and reviewed overrides in `config/liekan/zh-TW-overrides.json`; `pnpm liekan:zh-tw --check` fails when they are stale. Records persisted with a database locale constraint (analysis rollups and jobs, dashboard snapshots, history repair) and evidence exports store `zh-CN` for `zh-TW` requests and are converted at render time where the interface owns the text. Help catalogs load with the help view. Help search includes translated titles, bodies and crawler purpose labels while retaining article and crawler IDs, vendor markers, UA examples, robots tokens and code bytes. `text` formats application-owned messages, and `system` adapts application-owned status text. Raw user content is rendered directly. Semantic metric contexts distinguish pageviews, browser sessions and anonymous visitors. Display translations never replace the keys used to select cards, filter rows or sort data.

Actions and form values keep their canonical identities across language changes. The catalog checker permits a translated value only for an anonymous, read-only display field with a static application-owned label. Pending notifications keep the canonical message and format it in the current interface language when shown.

Localized table cells carry canonical display values for sorting through `TableCell`; the wrapper renders its children without adding a DOM element. Its `sortValue` contains canonical text or existing page-label helpers and is checked for translated identity leakage. Its `searchValue` supplies the explicit English display alongside canonical and current text, retaining raw names and paths. Filled message templates preserve whitespace within raw names. Table, geographic and help search include Chinese and English labels independently of the display language, keeping an existing search stable during a switch. Imported content categories, visitor device values and unrecognized bot-rule draft types keep their supplied labels.

New AI analysis requests accept optional `locale`, captured on submission. UI changes do not resubmit or cancel an active request. Historical answers retain their generation language. Omitted locale retains old request-hash behavior. Standard, geography and source-keyword exports accept the same optional locale. Human-readable CSV labels and display metadata use the submitted language; omitted locale retains the existing output, and machine JSON fields remain stable.

`scripts/liekan-i18n-check.mjs` verifies catalog coverage, stable message identities, placeholders and protected executable/query literals for all three catalogs, and rejects Simplified-only characters in the Taiwan catalog outside preserved publisher names. Locale, draft, metric, filtering, help, geography, AI and export regression tests accompany the existing original-reference and release checks. The Chinese reference assets and their SHA-256 manifests remain authoritative. English validation uses isolated browser contexts to check wrapping, keyboard access and narrow layouts without resizing an existing user browser.
